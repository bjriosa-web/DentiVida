# DentiVida – Aprende, previene y sonríe

Plataforma educativa de salud bucal (versión front-end).

## Cómo abrirla
1. Descomprime el zip.
2. Abre `index.html` en tu navegador (necesita internet para las fuentes y Chart.js).
3. Para publicarla, sube la carpeta completa a cualquier hosting estático (GitHub Pages, Netlify, etc.).

## Estructura
- `index.html`: estructura y los 9 módulos
- `css/styles.css`: estilos (paleta pastel celeste)
- `js/app.js`: lógica (rutina, juegos, temporizador, progreso, DentiBot, contacto)

## Notas
- Los datos del usuario se guardan en el navegador (localStorage); no hay base de datos.
- Las notificaciones solo funcionan con la página abierta.
- No incluye aún: Laravel, MySQL, login, panel de administración ni push.
- Contenido educativo: no sustituye la consulta con un odontólogo.
